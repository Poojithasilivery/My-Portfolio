# Commit 13: Add Contact Message History

## Objective
Display messages submitted through the portfolio contact form.

## Features
- Store submitted messages during the current app session
- Display sender name, email, message, and submission time
- View message history
- Delete messages after confirmation

## Concepts Used
- Dart model classes
- Lists and objects
- StatefulWidget
- ListView.builder
- Navigator
- AlertDialog

## Result
The portfolio can display and manage messages submitted during the current session.

Note: Messages are kept in memory and are cleared when the app restarts.
