# Commit 11: Save Theme Preference

## Overview
Implemented theme persistence in the Flutter portfolio application.

## Features
- Save the selected light or dark theme.
- Restore the saved theme when the application restarts.
- Keep the theme toggle on the Home and Projects screens.
- Preserve profile editing and live profile preview.
- Preserve project search, adding, editing, and deleting.

## Technologies Used
- Flutter
- Dart
- SharedPreferences
- ThemeData
- ThemeMode
