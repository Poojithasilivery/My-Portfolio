# Commit 10: Add Dark Mode Toggle

## Overview
Added a dark mode and light mode toggle to the existing Flutter portfolio application.

## Features
- Switch between light and dark themes.
- Change the appearance of the Home screen.
- Change the appearance of the Projects screen.
- Preserve profile editing and live profile preview.
- Preserve project search, add, edit, and delete functionality.
- Use Flutter ThemeData and ThemeMode.

## Technologies Used
- Flutter
- Dart
- StatefulWidget
- setState()
- ThemeData
- ThemeMode

## Screenshot
![Dark Mode Portfolio](screenshots/commit10_dark_mode.png)

## Result
Users can switch between light and dark themes using the theme icon in the app bar.
