# Commit 01: Flutter Project Setup and Initial Home Screen

## 1. Objective
To create a Flutter application and develop the initial home screen for my personal portfolio.

## 2. Tools Used
- Flutter SDK
- Dart programming language
- Visual Studio Code
- Git and GitHub

## 3. Implementation
- Created a new Flutter project named `my_portfoliop`.
- Configured the basic Flutter application structure.
- Designed an initial portfolio home screen.
- Added an app bar with a portfolio title.
- Used text, icons, containers, rows, and columns to organize the interface.
- Applied basic styling using Flutter's theme system.

## 4. Widgets Used
- `MaterialApp` – provides the basic application structure.
- `Scaffold` – creates the main screen layout.
- `AppBar` – displays the application title.
- `Text` – displays portfolio information.
- `CircleAvatar` – displays a circular profile area.
- `Row` and `Column` – arrange widgets horizontally and vertically.
- `Container` – provides spacing and styling.

## 5. Expected Output
The application displays an initial portfolio home screen with a title, profile area, and introductory information.

## 6. Testing
- Ran the Flutter application in Chrome.
- Checked whether the home screen displayed correctly.
- Verified that the main interface loaded without errors.

## 7. Learning Outcome
Learned how to create a Flutter project, use basic Flutter widgets, organize a home screen, and run the application.
